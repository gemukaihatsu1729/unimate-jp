1. 授業中妄想クライシス 〜黒板の前で俺だけが覚醒した件〜

教室の机・黒板・キャラクターをすべてコードベースのプロシージャル・ローポリモデル（SchoolBuilder / CharacterMesh）で構築したスマホ向け3Dアクションゲーム。 初回ロードを高速化しつつ、ヒットストップ、スローモーション、学習机の物理的な蹴り飛ばし、100位までのローカルランキングとSNSシェア機能を搭載しています。

制作背景と解決した課題

  • 課題1（スマホ3Dの重さ）：外部GLTF読み込みを排し、Box/Cylinder 等のジオメトリ結合と軽量シェーディングで即起動を実現。
  • 課題2（マルチタッチ干渉）：左仮想スティック・右4ボタン・背景カメラスワイプを pointerId ごとに完全分離。
  • 課題3（効果音ロード遅延）：Web Audio API によるゼロ依存シンセで校内チャイムや警報・爆発音を生成。

実装ハイライト・品質管理

  • 当たり判定と遮蔽物：CollisionSystem で移動衝突と銃弾遮蔽（机カバー）をAABBで分離管理。
  • テスト整備：CollisionSystem / RankingManager / ResultShare に対し Vitest で12件のユニットテストを実装。
  • 結果演出：生存人数別のツッコミ台詞分岐と X / LINE / Web Share API 対応シェア文生成を実装。

2. SHELTER MUSOU — 3Dゾンビ無双防衛

タイトル画面で装備を切り替えるとリアルタイムで3Dヒーローの武器が持ち替わり試し斬りできるライブプレビューと、 無制限ウェーブ制の防衛バトルを組み合わせたアクション×戦略ゲーム。1つの WebGL Canvas 上でシームレスにタイトルから戦場へ移行します。

制作背景と解決した課題

  • 課題1（3D空間上のタレット操作）：3D戦場の防衛パッドを Raycaster で直接タップ選択し、モバイルで迷わず建設・Lv3強化できるボトムシートを実装。
  • 課題2（群衆の押し合い処理）：多数ゾンビの重なりを防ぐ軽量なペアワイズ押し出し計算と 240 個上限のパーティクルプールで負荷を一定化。

実装ハイライト

  • 装備カスタマイズ：メイン武器3種・特殊タレット3種（＋共通オート機銃）・無双奥義3種をデータ駆動（data.ts）で定義。
  • 無限ウェーブ設計：Wave ごとに総数・HP・速度・出現間隔を算出する generateWave() と、3波ごとの Supply Drop パーク選択（6種）で長期的な戦略性を構築。

3. 無限フラッシュ暗算 — 加速する足し算の極限を見抜け

高校数学の無限級数をフラッシュ暗算形式にした教育×エンタメ作品。外部ライブラリゼロ（ランタイム依存なし）で、 高速フラッシュ表示、分数・平方根・対数対応の数式パーサー、SVG 収束可視化チャート、35種類の極限図鑑コレクションをすべて自前実装しています。

制作背景と解決した課題

  • 課題1（スマホのキーボード問題）：OSキーボードが画面を覆うのを防ぐため、4×4親指テンキーと問題に応じた5種数学記号ストリップを独自実装。
  • 課題2（等価表現の正誤判定）：0.5 と 1/2、1/√2 と √2/2、発散 と ∞ をすべて正解扱いできるよう独自トークナイザ＆再帰下降評価器を構築。

実装ハイライト・品質管理

  • 11カテゴリの問題生成：等比級数・部分分数・三角関数・フィボナッチ・階乗・発散トラップなどエンドレス自動生成にも対応。
  • テスト整備：answerParser / scoreManager / seriesBank に対し Vitest で16件の自動テストを実装。

4. METRO ESCAPE — ローポリ3Dバイク逃走チェイス

スマホの親指1本スライド操作に特化した、ローポリ3Dバイク警察チェイスゲーム。シード値ベースの決定論的チャンクストリーミングにより、どこまでも走り続けられる都市生成と軽快な60fps描画を両立しています。

制作背景と解決した課題

  • 課題1（無限都市のメモリ管理）：StreamingCity で 7×7 チャンク（49区画）のみを動的ロード／解放し、チャンク破棄時に InstancedMesh.dispose() を明示してメモリ増加を防止。
  • 課題2（片手操作と爽快感）：オートアクセル＋SlideInputManager の指1本横スライド操作で鋭いコーナリングとドリフト自動ミニターボを実現。
  • 課題3（直進・狭路ハメ対策）：全面封鎖検問・白バイの路地裏追尾・computeBustedDelta による失速確保判定で緊張感のある駆け引きを設計。

実装ハイライト・品質管理

  • シード都市生成：街区配置・交差点・ジャンプ台・ニトロ缶配置を CityLayout で決定論的に生成し、毎回異なる逃走ルートを構築。
  • テスト整備：CityLayout / Collision / ResultShare / computeBustedDelta に対し Vitest で14件の自動テストを実装。

Architecture & Stack

設計・運用アーキテクチャ一覧

サイト本体と全ゲームを 1 つのモノレポにまとめ、開発効率・配信速度・UX安全性を一貫して管理しています。

言語・ビルド基盤 TypeScript 5.7 / Vite 6 / npm Workspaces site と games/* を独立したワークスペースとして管理し、scripts/build-all.mjs で単一 dist/ へ統合出力。
3D・UI・サウンド Three.js 0.172 / Web Audio API / SVG 外部アセットに依存しないプロシージャル設計により、初回バンドルサイズを抑えつつ滑らかな描画と効果音再生を実現。
品質管理・自動検証 Vitest / 独自 verify-dist.mjs 合計42件のゲームロジックテストに加え、ビルド成果物の全リンク切れ・サイトマップ整合・広告配置順序を自動検証。
