外部音声ファイルゼロ！Web Audio API でブラウザゲームのチャイム・警報・爆発音を合成する実装手法

公開日: 2026-11-21 カテゴリ: ゲーム開発・サウンド

ブラウザゲームで効果音を鳴らすとき、MP3 や WAV ファイルを数十個用意してプリロードする方法は一般的ですが、 「通信量が増える」「初回起動時の待機時間が伸びる」「効果音ごとの音量バランスやバリエーションをコードから微調整しにくい」という悩みが出がちです。 そこで Unimate JP の3作品（授業中妄想クライシス・SHELTER MUSOU・無限フラッシュ暗算）では、 外部音声ファイルを一切使わず、ブラウザ標準の Web Audio API だけで全効果音をリアルタイム合成しています。

1. なぜゼロ依存シンセを選んだのか

  • 通信・ロード時間ゼロ：音声アセットのフェッチ待ちがないため、URLを開いた瞬間にタイトル画面が操作できます。
  • 状態に応じた動的変化：コンボ数に応じて音程を上げたり、軽い攻撃と強撃でエンベロープを変えたりする演出が数行で書けます。
  • 著作権・ライセンス管理が不要：すべての音がブラウザ内で数式・波形から生成されるため、外部素材サイトの利用規約管理コストが発生しません。

2. 最重要ポイント：iOS Safari 等の自動再生制限の解除

モバイルブラウザでは、ユーザーのジェスチャー（タップやクリック）なしに AudioContext から音を鳴らすことが制限されています。 そこで AudioManager に unlock() メソッドを用意し、「スタートボタン押下」や「仮想スティック・攻撃ボタンの初回 pointerdown」といった入力イベントの同期コールバック内で初期化と ctx.resume() を呼び出しています。 

unlock(): void {
  try {
    if (!this.ctx) {
      const AudioCtx =
        window.AudioContext ||
        (window as unknown as { webkitAudioContext: typeof AudioContext }).webkitAudioContext;
      if (!AudioCtx) return;
      this.ctx = new AudioCtx();
    }
    if (this.ctx.state === 'suspended') {
      void this.ctx.resume();
    }
  } catch {
    // 制限環境でもゲーム本体は止めない
  }
}

重要なのは、非同期処理（setTimeout や Promise.then）の外側、つまりユーザーが画面に触れたそのイベントハンドラの先頭で unlock() を呼ぶことです。これにより iOS Safari でも確実にオーディオがアンロックされます。

3. よく使う4つの効果音合成レシピ

基本は OscillatorNode（波形）と GainNode（音量エンベロープ）の組み合わせ、そして打撃・風切り・爆発に使うホワイトノイズ（AudioBuffer）の 2 系統です。

① 学校のチャイム（Triangle波のシーケンス）

「授業中妄想クライシス」の冒頭で鳴るウェストミンスターの鐘は、周波数 [659.25, 523.25, 587.33, 392.0] Hz の triangle 波を 0.42 秒間隔でスケジュールして鳴らしています。 exponentialRampToValueAtTime(0.001, ...) で余韻を減衰させるだけで、驚くほど「学校のチャイムらしさ」が出ます。

② 緊急警報サイレン（Sawtooth波のピッチスイープ）

テロリスト突入時のアラームは、倍音を多く含む sawtooth 波を使い、880Hz から 640Hz へ 0.18 秒かけて線形下降させるパターンを 4 回繰り返すことで緊張感を演出しています。

③ 爆発音・打撃音（Sine波の低音落下 ＋ ローパスノイズ）

爆発や重いヒットには、「140Hz → 28Hz へ急降下する sine 波」と「ローパスフィルタを通したホワイトノイズ」を重ねています。 低音の「ドン！」という芯と、ノイズの「バシャッ／ドゴッ」という質感を混ぜることで、スマホの小さなスピーカーでも迫力のある打撃感になります。

④ パリィ・金属音（倍音クラスター）

竹刀の閃光パリィ時などは、[1320, 1980, 2640] Hz の sine 波を 15ms ずつずらして同時に鳴らすと、澄んだ金属の共鳴音が生まれます。

4. ミュート切り替えとメモリ・ノード解放の注意点

OscillatorNode は一度 stop() すると自動破棄されるワンショット設計になっていますが、使い捨ての GainNode を大量に繋ぎっぱなしにすると負荷の原因になります。 osc.stop(endTime) を必ず明示すること、そしてゲームプレイ中に同じフレーム内で何十体も同時ヒットした際に音が割れないよう、最大ゲインを 0.15〜0.28 程度に抑えることが安定運用のコツです。

今回解説したシンセ効果音は、授業中妄想クライシス と SHELTER MUSOU で実際の打撃音・チャイム・爆発音として体験できます（画面右上の 🔊 ボタンでいつでもミュート切り替え可能です）。
