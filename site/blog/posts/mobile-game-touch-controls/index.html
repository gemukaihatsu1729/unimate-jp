スマホブラウザで「移動しながら攻撃」を実現する Pointer Events マルチタッチ仮想スティック実装

公開日: 2026-11-21 カテゴリ: ゲーム開発・UI設計

スマートフォンのブラウザでアクションゲームを動かそうとすると、PC向けのマウスイベント（mousedown / mousemove）だけでは「左手でキャラクターを動かしながら、右手で攻撃や回避ボタンを連打する」操作が成立しません。 さらにモバイルブラウザ特有の「画面のスクロール・引っ張り更新（Pull-to-refresh）・ダブルタップ拡大・文字選択」が暴発すると、一気に遊びにくくなります。

この記事では、授業中妄想クライシス と SHELTER MUSOU で採用している TouchInputManager の設計をもとに、快適なマルチタッチ操作を作るための実装パターンを解説します。

1. なぜ Touch Events ではなく Pointer Events なのか

昔の実装では touchstart / touchmove を使うのが定番でしたが、現在ではマウス・タッチ・スタイラスを同じコードで扱え、指1本ごとに一意の e.pointerId が発行される Pointer Events（pointerdown / pointermove / pointerup / pointercancel）が非常に扱いやすいです。

  • PCのマウスでデバッグするときも、スマホの実機タッチと全く同じイベント経路を通る
  • 指ごとに pointerId を保持するだけで、スティック・カメラ・各ボタンが互いに干渉しない
  • element.setPointerCapture(e.pointerId) を呼んでおけば、指がスティック枠の外側へ滑っても追従し続ける

2. 仮想スティックの計算：デッドゾーンとスプリント判定

ジョイスティックの入力処理では、親指が少し触れただけの誤動作を防ぐ「デッドゾーン」と、最大まで倒したときの「ダッシュ（スプリント）判定」を入れると手触りが格段に良くなります。 

const dx = clientX - this.joyOriginX;
const dy = clientY - this.joyOriginY;
const dist = Math.hypot(dx, dy);
const clamped = Math.min(dist, this.joyMaxRadius);
const angle = Math.atan2(dy, dx);

const kx = Math.cos(angle) * clamped;
const ky = Math.sin(angle) * clamped;
const norm = clamped / this.joyMaxRadius;

if (norm < 0.12) {
  // 12%未満は遊び（デッドゾーン）として移動しない
  this.moveX = 0;
  this.moveY = 0;
  this.sprinting = false;
} else {
  this.moveX = kx / this.joyMaxRadius;
  this.moveY = -(ky / this.joyMaxRadius); // 画面上向きを前進(+1)に変換
  this.sprinting = norm > 0.82; // 82%以上倒すとダッシュ
}

また、指を離したとき（pointerup）だけでなく、通知バナーや画面端ジェスチャーで入力が中断されたときの pointercancel でも同じリセット処理を呼ぶのが、移動入力が押しっぱなしになるバグを防ぐ鉄則です。

3. 攻撃ボタン連打・長押しをゲームループ側へ安全に渡す

UIイベントはブラウザの描画フレームとは非同期に飛んでくるため、イベント内で直接攻撃関数を呼ぶのではなく、「キュー（フラグ）」に積んでおき、requestAnimationFrame のゲームループ先頭で consumeState() によって回収する構成にしています。 また bindButton 内で e.preventDefault(); e.stopPropagation(); を呼ぶことで、ボタンの下にある背景のカメラスワイプ領域へイベントが貫通しないようにしています。

4. モバイルブラウザの誤動作を封じる CSS ルール

JavaScript 側の制御に加えて、CSS 側で以下の設定を入れておくと実機での快適さが大きく変わります。

  • touch-action: none;：ゲーム画面・操作ボタン上でピンチズームやスクロールを無効化（スクロールが必要なリザルト画面のみ touch-action: pan-y; を許可）。
  • user-select: none; -webkit-user-select: none;：ボタン長押し時にテキスト選択メニューが出るのを防止。
  • env(safe-area-inset-bottom)：iPhone のホームバーに仮想スティックや攻撃ボタンが重ならないよう余白を確保。
  • 入力欄フォントサイズ 16px 以上：「授業中妄想クライシス」の名前入力欄のようにテキスト入力がある箇所は font-size: 16px にし、iOS の自動ズームインを回避。
実際のマルチタッチ操作は 授業中妄想クライシス および SHELTER MUSOU で、移動スティック＋攻撃＋回避を同時に押しながら試すことができます。
