3D無双×タワーディフェンスのゲームバランス設計：ウェーブ難易度曲線と強化パークの組み立て方

公開日: 2026-11-21 カテゴリ: ゲームデザイン・システム設計

アクションゲームとタワーディフェンスを掛け合わせる際、最も難しいのが「主役がどちらに傾きすぎても面白さが半減する」点です。 砲塔が強すぎればプレイヤーが突っ立っているだけでクリアできてしまい、逆にヒーローが強すぎれば砲塔を建てる意味が薄れます。 SHELTER MUSOU では、この両輪を噛み合わせるために src/data.ts 上で役割分担と難易度曲線を細かく設計しました。

1. 敵種別ごとの「ヒーロー担当」と「タレット担当」の住み分け

ゾンビ 5 種類のステータスをあえて極端に振り分けることで、「自分で斬りに行くべき相手」と「砲塔に任せたい相手」が自然に分かれるようにしています。

  • ウォーカー（HP 85 / 速度 3.6）：群れで押し寄せる雑魚。ヒーローの無双斬撃で気持ちよく薙ぎ払い、コンボと無双ゲージを稼ぐ「爽快感の源」です。
  • ランナー（HP 55 / 速度 6.8）：足が速く、プレイヤーが反対側で戦っている隙に避難所を削ってくる厄介な存在。安価なオート機銃（55⚙️）やテスラ電撃塔の減速で迎撃する役割を持たせています。
  • ボマー（HP 125 / 避難所ダメ 95）：自爆特性を持つため、近接攻撃だけで倒そうとするとヒーローも大ダメージを受けます。ミサイル砲塔や強撃・回避で距離を取りながら処理する緊張感を作ります。
  • ブルート＆タイタン・ボス（HP 340 / 2200）：耐久が高くタレットだけでは削りきれないため、高火力のサンダーハンマーや無双奥義、強化した砲塔の集中砲火を合わせる必要があります。

2. 無制限ウェーブを破綻させない数式スケーリング

エンドレスモードでは、いつまでも終わらない作業ゲーにならないよう、generateWave(wave) でウェーブごとに敵数・HP・速度・出現間隔を非線形に引き上げています。 

const count = Math.floor(22 + wave * 9.5 + Math.pow(wave, 1.55));
const hpMult = 1 + (wave - 1) * 0.28 + Math.pow(Math.max(0, wave - 2), 1.55) * 0.08;
const speedMult = Math.min(2.15, 1 + (wave - 1) * 0.045);
const spawnInterval = Math.max(0.06, 0.34 / (1 + (wave - 1) * 0.22));

ここで意識したのは「移動速度倍率に上限（2.15倍）を設けること」と「Wave 1〜3 で敵の種類を段階的に解禁すること」です。 速度が無制限に速くなると当たり判定や回避が理不尽になるため、中盤以降は敵の数・HP・ボス出現数（3ウェーブごと＋Wave 7以降の奇数ウェーブ）で圧力を高める設計にしています。

3. 3ウェーブごとの Supply Drop（強化パーク）によるビルド感

毎回同じ展開になるのを防ぐため、3ウェーブ突破ごとに 6 種類の強化パークからランダムで 3 枚が提示され、1 つを選ぶローグライト要素を入れました。

  • 攻撃特化：「無双の剛力（ダメージ +18%）」「極大斬撃波（攻撃範囲 +16%）」
  • 砲塔・防衛特化：「防衛砲塔オーバークロック（威力 +18% & 連射 +12%）」「避難所チタン装甲（最大HP +140 & 回復）」
  • リソース・回転特化：「無双ソウル覚醒（ゲージ増加 +25% & 即100%充填）」「物資回収ドローン（スクラップ +20% & 即45⚙️支給）」

「今の避難所HPなら回復を取るべきか、それとも砲塔オーバークロックで押し切るべきか」という毎回違う判断が生まれ、リプレイ性が大きく向上しました。

武器3種・タレット4種・奥義3種の詳しい数値データは ゲームポータルの SHELTER MUSOU 攻略データ にまとめています。ぜひ自分だけの最強ビルドを試してみてください！
