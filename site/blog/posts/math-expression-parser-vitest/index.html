「1/√2」と「√2/2」を同じ正解と判定する：数学ゲーム向け数式パーサー設計と Vitest 自動テスト

公開日: 2026-11-21 カテゴリ: アルゴリズム・テスト

無限フラッシュ暗算 を開発するうえで最もこだわったのが「解答の正誤判定の納得感」です。 たとえば答えが 1/2 のとき、0.5 と書いても数学的には正解ですし、有理化前の 1/√2 と有理化後の √2/2 も同じ値です。 もし文字列の一致だけで不正解にされたら、プレイヤーにとって理不尽なゲームになってしまいます。

そこで外部の数式ライブラリや危険な eval() を使わずに、軽量で安全かつ直感的な独自数式パーサー（src/game/answerParser.ts）を実装しました。

1. ステップ1：全角記号・日本語キーワードの正規化

スマホテンキーからの入力だけでなく、PCキーボードから直接入力するプレイヤーも想定し、まず normalizeAnswerInput() で表記ゆれを吸収します。

  • 全角数字や全角演算子（＋ − ÷ × ／）を半角に統一
  • 発散・inf・infinity をすべて ∞ に変換
  • sqrt → √、pi → π、log(2)・ln(2) → ln2 に正規化

2. ステップ2：トークナイズと再帰下降構文解析（Recursive Descent）

正規化した文字列を NUMBER・CONST（π, e, ln2）・OP・SQRT・SQ（2乗）・カッコのトークン列へ分解します。 また、数式では「2π」「3√2」「2(1+3)」のように乗算記号 * を省略する書き方が自然なため、暗黙の乗算も処理できるようにしました。

構文解析は演算子の優先順位に沿って parseExpr (+,-) → parseTerm (*,/) → parseUnary (+,-) → parsePower (^, ²) → parsePrimary (数値, 定数, √, カッコ) の順に再帰で評価します。 負の数の平方根やカッコ閉じ忘れが入力されたときは、単なる「不正解」ではなく具体的なエラーメッセージ（「カッコが閉じられていません」など）を返し、リトライしやすくしています。

3. ステップ3：有限値・発散（∞）の判定と許容誤差

if (expected.kind === 'infinity') {
  return { valid: true, correct: parsed.kind === 'infinity', ... };
}
// 有限値の場合は浮動小数点誤差を吸収するため 1e-9 以内で一致判定
const correct = Math.abs(parsed.value - expected.value) <= 1e-9;

1/√2 を評価した値と √2/2 を評価した値の差は IEEE 754 倍精度浮動小数点でも 1e-16 程度に収まるため、許容誤差 1e-9 によって確実に同じ正解として判定されます。一方で 0.707 のような粗い近似入力はきちんと弾けるちょうどよい閾値です。

4. Vitest による 16 件の自動テストで数学的破綻を防ぐ

数式パーサー・スコア計算・35種類の問題バンク（seriesBank.ts）には Vitest のテストスイートを用意し、モノレポの npm test で毎回検証しています。

  • answerParser.test.ts：分数・小数・有理化前後・定数乗算・発散・不正構文エラーの検証
  • seriesBank.test.ts：全問題が収束値・発散仕様と一致しているか、部分和の数値シミュレーションを自動確認
  • scoreManager.test.ts：早期解答ボーナス、リプレイ時ペナルティ、コンボ倍率上限（2.5倍）と段位判定の境界チェック
今回解説したパーサーが実際に動く様子は、無限フラッシュ暗算 で 1/√2 や 0.5 などを入力して体験できます。
