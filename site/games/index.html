1. 授業中妄想クライシス 〜黒板の前で俺だけが覚醒した件〜

基本操作

  • 左ドラッグ（仮想スティック）：主人公の移動（大きく倒すとスプリント）
  • 👊 攻撃ボタン：通常攻撃（装備中の備品によって威力・リーチが変化）
  • 🔥 備品技ボタン：クールダウン付きの武器専用スキルを発動
  • 💨 回避ボタン：銃撃やボスの範囲攻撃をすり抜ける無敵ロール
  • 机アクション（状況ボタン）：備品の回収、学習机を蹴り飛ばす強攻撃、バリケード活用
  • ⚡ 妄想覚醒：ゲージ100%で発動し、一定時間ステータスが大幅強化

全3ウェーブ進行とランク判定

  • Wave 1（教室突入！）：教室前方・後方から一般兵と遠距離ガンナーが突入。
  • Wave 2（廊下防衛戦！）：廊下エリアが開放され、正面攻撃を防ぐ「盾部隊」が出現。
  • Wave 3（首領降臨！）：ボス「ブラック・ファントム」と増援が出現。撃破で制圧成功。
  • ランク基準：SS（クリア＋全員生存＋21,000pt以上）／ S（16,500pt〜）／ A（11,500pt〜）／ B（7,000pt〜）

2. SHELTER MUSOU — 3Dゾンビ無双防衛

ヒーローを直接動かしてゾンビを斬り伏せる「無双アクション」と、倒したゾンビから回収したスクラップ（⚙️）で拠点に防衛砲塔を建てる「タワーディフェンス」を融合させた作品です。 出撃前に「メイン武器」「特殊タレット」「無双奥義」の3カテゴリを選び、3ウェーブごとに届く強化物資（Supply Drop）を取りながらどこまでウェーブを進められるかに挑戦します。

基本操作と拠点管理

  • 左スティック：3D戦場での移動（背景スワイプで視点角度の調整も可）
  • ⚔️ 斬撃（連打／長押し）：長押しで自動コンボが連続し、押し寄せる群れを薙ぎ払う
  • 💥 強撃・💨 回避：クールダウン付きの広範囲強攻撃と無敵ダッシュ
  • 🏗️ 砲塔設置・🔧 避難所修理：拠点パッドをタップ（または近接ボタン）で建設・Lv3まで強化
  • ☄️ 無双奥義：無双ゲージ100%で戦場全体に大効果を発揮する奥義を発動

注意すべきゾンビ5種の対策

  • ウォーカー（HP85）：標準的な群れ。正面斬撃と機銃で難なく処理可能。
  • ランナー（速度6.8）：超高速で避難所へ直行する赤ゾンビ。機銃・電撃塔で足を止めよう。
  • ブルート（HP340）：高耐久の大型種。ハンマーの強撃や火炎塔の継続ダメージが有効。
  • ボマー（避難所ダメ95）：接近すると自爆するオレンジ個体。最優先で遠距離処理・回避必須。
  • タイタン・ボス（HP2200）：3ウェーブごと（Wave 7以降は奇数波にも）に出現する巨大ボス。

3. 無限フラッシュ暗算 — 加速する足し算の極限を見抜け

画面に現れては消える数列の項から規則性を読み取り、無限に足し合わせた「極限値」を専用テンキーで解答する数学アクションゲームです。 「5問チャレンジ」と「エンドレス挑戦（ライフ3）」の2モードを用意し、正誤判定の直後には部分和が極限値へ収束（または発散）していく SVG グラフと数学的解説が表示されます。

スコア計算と神速ボーナス

  • 基本点：正解ごとに一律 1,500 pt
  • 神速ボーナス：フラッシュ途中で「⚡ わかった！」から早期解答すると +800 pt（通常解答は10秒以内で最大 +650 pt）
  • コンボ倍率：連続正解で 1.00倍 → 最大 2.50倍 まで上昇
  • リプレイ注意：「↺ もう一度」を使うと正解時のスピードボーナスが 0 になるため、一発で規則を見抜くのが高得点の鍵

段位システム（5級 〜 ∞神）

  • 初心者〜中級：5級（そろばんビギナー）→ 1級 → 初段 → 三段 → 五段
  • 上級〜達人：八段（超速収束マスター）→ 十段（無限暗算師範）→ 名人（解析の覇者）
  • 最高位：∞神（極限到達者）（5問モード 14,500pt 以上／エンドレス 32,000pt 以上で認定）
  • 入力サポート：1/2 と 0.5、1/√2 と √2/2、発散 と ∞ などの等価表記をすべて正解扱い

「極限図鑑」収録 全11カテゴリ＆解法ヒント

カテゴリ 代表的な出題イメージ 見抜きのポイント
等比・循環 1 + 1/2 + 1/4 + 1/8 + … = 2 初項 a、公比 r（|r| < 1）を見抜いたら a / (1 - r)。循環小数も同様に解けます。
混合等比 奇数項と偶数項で別々の公比が混ざる級数 1つ飛ばし（2つの等比級数の和）に分解してそれぞれ足すのがコツ。
三角関数 sin(π/3), cos(nπ) を含む級数・極限 周期性に注目。値が振動し続ける場合は収束せず発散扱いになる問題も。
部分分数 1/(1·2) + 1/(2·3) + 1/(3·4) + … = 1 1/k(k+1) = 1/k - 1/(k+1) で隣り合う項が打ち消し合う「望遠鏡和」です。
対数の和 log(2/1) + log(3/2) + … や減衰対数 対数の足し算＝真数の掛け算。約分で綺麗に消えるか発散するかを見極めます。
有理化 (√2 - 1) + (√3 - √2) + … 型の項 平方根の差に分解すると望遠鏡和になるパターンが多いです。
等差×等比 1·(1/2) + 2·(1/4) + 3·(1/8) + … = 2 公比 r を掛けて引く定番解法。覚えておくと即答できます。
フィボナッチ フィボナッチ数列を含む逆数級数や比率 分子と分母の漸化式や黄金比との関係に注目すると極限が見えます。
階乗・e 1 + 1/1! + 1/2! + 1/3! + … = e マクローリン展開でおなじみのネイピア数 e や関連定数に帰着するパターン。
有名極限 バーゼル問題（π²/6）やライプニッツ級数（π/4） 数学史に残る有名級数。最初の3項（例: 1, -1/3, +1/5）から知識で即答可能！
発散トラップ 調和級数（1 + 1/2 + 1/3 + … = ∞）など 「項が0に近づくのに和は無限大に発散する」罠問題。落ち着いて ∞ を選択しましょう。

4. METRO ESCAPE — ローポリ3Dバイク逃走チェイス

指1本の横スライド操作でオート走行するバイクを操り、シード値で無限に生成され続ける3D都市の中を警察の包囲網から逃げ続けるタイムサバイバルゲームです。 耐久回復アイテムやスコア稼ぎは一切なく、純粋な「逃走タイム」のみで伝説のライダーランクを目指します。

基本操作とサバイバルルール

  • 指1本スライド（PCは A/D・←/→）：バイクは自動で前進し、スライド量に応じて鋭くコーナリング。大きく切り込むとドリフト状態に入り、戻すと自動でミニターボが発動します。
  • ⚡ ニトロ（Space / Shift）：初期チャージ 0%、60% 以上で発動（1.65秒間 1.38倍加速）。路地・公園・広場のニトロ缶やドリフト・ニアミスでチャージされます。
  • 耐久回復なし＆逃走タイム一本勝負：マシン損傷の回復手段はありません。障害物・警察車両への正面衝突を避けて限界タイムに挑みましょう。
  • 無限自動生成シティ：タイトル画面の「🎲 街を再生成」から、遊ぶたびにレイアウトが変わる新しい街シードを生成できます。

手配度（★1〜★5）と逃走ランク基準

  • ★1（0s〜 初動追跡）：パトカー＆白バイが緊急出動（最大3台）。
  • ★2（15s〜 包囲網＆検問）：高速インターセプター登場＆全面封鎖検問を展開（最大5台）。
  • ★3（35s〜 機動隊突入）：重装甲の機動隊SUV投入（最大6台）。
  • ★4（60s〜 空陸立体追跡）：警察ヘリが上空からサーチライト照射（最大7台）。
  • ★5（95s〜 都市完全封鎖）：全警察部隊による総力包囲網（最大9台）。
  • ランク基準：SS（2:00.0〜）／ S（1:15.0〜）／ A（0:45.0〜）／ B（0:22.0〜）／ C（〜0:21.9）

5. DOCTOR CARGO — 夕焼けヘリ振り子移送アクション

夕焼け空の下、ドクターヘリ風の機体から4本のロープで吊られたワイヤーケージを運び続ける2D物理振り子アクションです。 ヘリの加速・減速で生まれる振り子の揺れを読み、ウインチ巻上で姿勢を整えながら鉄塔・気球・風力タービン・突風地帯を抜けて中継ヘリポート（450m・950m・1500m…）を目指します。

基本操作とスコアテクニック

  • ドラッグ操縦（PCは WASD / 矢印キー）：8方向へ機体を自在に操縦。加速するとカゴが後ろに振れ、逆方向へ軽く切り返すと揺れを打ち消せます。
  • 🪝 ウインチ巻上（右下ボタン / Space / Shift）：押している間ロープを巻き上げてカゴを機体直下へ近づけ、揺れを強力に減衰させます（スタミナ制）。
  • SWING CATCH & ニアミス：カゴ側でスターリングを通過すると +350pt、障害物スレスレ通過で CLOSE! ボーナス（最大5コンボ）。
  • 中継ヘリポート着地：450m ごとに現れる緑の H パッドへカゴをそっと降ろすと燃料100%＆HP回復！
